A clipboard, lit.

Lume is a native open-source clipboard manager for macOS 26. It lives in your menu bar, syncs through your iCloud, and is engineered against performance budgets enforced by tests.

01 / what

A real macOS app, not a port.

Lume is built on Apple's Liquid Glass material, drives SQLite FTS5 for search at 100k+ rows in a single frame, and uses GRDB with a 1-writer / 4-reader pool so the popover never waits on a write.

It captures text, colors, and file paths by default. Images are opt-in because storing pixel data balloons databases, and we'd rather you decide. Each kind has its own retention window.

Sync goes through your private iCloud database via a custom CloudKit engine. No Lume servers. No third party. No telemetry. The codebase has one runtime dependency (GRDB) and uses Carbon for the global hotkey because it's the right tool.

02 / features

Dense by design.

capture
Text, RTF, HTML, colors (hex + NSColor), file paths. RTF and HTML formatted blobs ride alongside plain text so you can paste back with formatting. Paths are stored as strings — no file body.
smart filters
URLs, Emails, Today, This Week. Computed at filter time via NSDataDetector and a tight email regex. No tagging, no setup.
quick transforms
lowercase, uppercase, trim, JSON pretty, base64 ↔, URL ↔. One click in the detail pane. The result is copied and persisted back to history. Each chip only shows when meaningful.
snippets
Saved boilerplate with variables: {{date}} {{time}} {{datetime}} {{clipboard}}. Insert from a menu in the popover footer or the Snippets tab.
tags
Color-coded tags managed in Settings → Tags. Apply or remove from the detail pane. Foreign-key cascade handles deletion cleanly.
edit mode
Inline TextEditor on a clip. Save & Copy persists the edit as a new history entry rather than mutating the original.
encryption
Sensitive clips sealed with ChaCha20-Poly1305. Key lives in iCloud Keychain (kSecAttrSynchronizable=true). Ciphertext can sync; plaintext never does.
sync
CloudKit private database, custom zone, change-token delta fetch. Conflict policy: max(lastSeenAt) for content, max(hitCount), OR(isPinned). Disabled gracefully when the iCloud entitlement is missing.
retention
Per-kind windows: text/colors, images, files. Pinned clips are never purged. Defaults: 30 d / 7 d / 14 d. Bulk Compact and Clear in Settings.
search
SQLite FTS5 with unicode61 tokenizer. Native NSSearchField in the toolbar. Identical placement and height across every tab.
custom hotkey
Click-to-record field in Settings → Hot Keys. NSEvent local monitor captures the chord; persisted as JSON; re-registered through Carbon. Default ⌥⌘V.
popover style
Default (two-line) or Minimal (single-line, hover reveals meta). Toggle in Settings → General.
keyboard
⌘1–9 quick-paste in popover. ⌘N new snippet. ⌘ , Settings. Carbon RegisterEventHotKey for the global hotkey. Sandbox-OK.
stats
Swift Charts bar chart for the last 30 days. Top apps with their icons. Storage used. Total / pinned / encrypted counts.

04 / privacy

Open source. No telemetry. Ever.

Lume reads NSPasteboard.general on a 0.4 s timer and stores everything locally. Nothing leaves your machine unless iCloud Sync is enabled, in which case the only network destination is your own private CloudKit database.

No analytics. No remote config. No phone-home of any kind. The source is on GitHub. Read it, fork it, audit it.

05 / install

Two ways in.

Lume ships unsigned from GitHub Releases. The first launch needs a Gatekeeper bypass — strip the quarantine flag, or right-click and choose Open. 

xattr -dr com.apple.quarantine /Applications/Lume.app

Or build from source:

git clone https://github.com/k6w/lume.git
cd lume
brew install xcodegen
./scripts/run.sh        # build + launch
./scripts/run.sh test   # 29 tests, 0 failures
